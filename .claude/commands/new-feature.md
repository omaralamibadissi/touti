---
description: Démarrer une nouvelle feature avec branche Git, TODOs et checklist
---

Tu vas aider Omar à démarrer une nouvelle feature proprement :

1. Demande le nom de la feature (kebab-case)
2. Crée une branche Git `feat/<nom>` depuis `main` après un `git pull`
3. Ajoute une entrée dans `docs/decisions/` si la feature implique un choix d'archi
4. Crée une liste de tâches pour :
   - Spécifier les types partagés dans `shared/src/`
   - Implémenter côté `server/` si besoin
   - Implémenter côté `mobile/` si besoin
   - Tester
   - Commiter avec un message clair
5. Rappelle à Omar de `git push` à la fin

Ne commence pas à coder avant d'avoir la confirmation d'Omar sur le plan.
